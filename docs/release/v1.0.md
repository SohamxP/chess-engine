# PlySense v1.0.0

**Personal chess improvement: play, reflect, improve.**

PlySense combines a custom Java chess engine with browser-local Stockfish
analysis, evidence-backed mistake detection, and adaptive personal training.

## What ships

- **Java 25 / Spring Boot chess opponent:** legal-move generation including
  castling, promotion, en passant and automatic/claimable draws; negamax,
  iterative deepening, alpha-beta pruning, quiescence and a history-aware
  transposition table.
- **Game Review:** PGN import, full move replay with standard SAN notation,
  a local Stockfish analysis worker, deeper checks for suspicious decisions
  and versioned evaluation caching.
- **Personal Mistake Patterns:** three narrowly verified categories—missed
  mate-in-one, missed unprotected material and exposed major pieces—grouped
  by distinct saved games with direct links to the original position.
- **Decision Lab:** hidden-best-move drills, written reflections, bounded
  attempt history, adaptive scheduling from recurring evidence, and
  progress shown with real attempt denominators.
- **Local-first game library:** 2,000-game IndexedDB capacity, migration from
  the 50-game localStorage archive, pagination, and portable JSON
  export/restore for games, training cards and durable analysis evaluations.
- **Verification:** canonical perft positions, search score/move-equivalence
  checks, Vitest unit tests, browser Playwright flows, Docker integration and
  a production HTTP smoke test in GitHub Actions.

## Measured engineering result

Search status used to generate legal moves and then search ordering
generated the same moves again. The optimization reuses one enumeration.

The depth-2 **GitHub Actions** A/B sampler (7 measured runs per position,
2 warmups, same runner/JDK in a single job) reported:

| Position | Old search median | Reused moves median | Lower latency |
| --- | ---: | ---: | ---: |
| Starting | 5.975 ms | 4.256 ms | 28.8% |
| Tactical | 6.301 ms | 4.765 ms | 24.4% |
| Pawn endgame | 0.376 ms | 0.282 ms | 25.0% |

The two algorithms returned **identical chosen moves, scores and search
statistics** on these cases. Timings on shared CI hardware are preliminary,
not a guaranteed speedup at deeper search depths or on other computers.
See [benchmark methodology](../benchmarks/README.md).

## Known limitations

- Saved games, training data and analysis cache belong to this browser and
  do not automatically sync across devices. Export backups yourself.
- Existing games in Java server memory cannot be resumed after a service
  restart, though stored move snapshots remain reviewable.
- Only **three supported tactical error patterns** are classified, so a
  missing finding does not prove correct play.
- PGN import supports standard chess mainlines (not all comments,
  variations or Chess960); previews remain limited to 50 games per batch.
- Decision Lab results measure **practice performance**, not a validated
  increase in chess skill or Elo.
- Stockfish Lite runs locally and may require multiple passes for long games.
  This project is not an official Chess.com or Lichess client.
